# Coding Standards

These are starter standards. Adjust the JSON values in `coding-standards.json` and the review
expectations below to match the conventions and risk profile of the repository.

## Review expectations

- Keep changes focused and follow existing project conventions.
- Use the configured function and variable naming conventions.
- Prefer small, clear functions and reuse existing logic instead of duplicating it.
- Handle errors consistently and avoid exposing credentials or sensitive data.
- Keep formatting clean and document behavior changes where appropriate.
- Treat automated and AI-generated findings as review signals that may require human judgment.
